# Online Cab Booking System

A web-based cab booking application with role-based access for Passengers,
Drivers, Admins and Super Admins.

## Features (planned)
- Passenger: register, book/cancel rides, trip history, ratings
- Driver: availability, accept/reject rides, earnings
- Admin: manage users, vehicles, fares, reports
- Super Admin: manage admins, permissions, system logs

## Technologies Used
- HTML, CSS, JavaScript (DOM, Fetch/AJAX)
- Node.js 
- MySQL / MariaDB
